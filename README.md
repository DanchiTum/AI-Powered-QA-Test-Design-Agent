# AI-Powered QA Test Design Agent

AI QA agent that takes a website URL, lets you select Functional and/or Negative tests, and generates automation code.

## Flow

1. Enter a website URL  
2. Select test types (Functional, Negative, or both)  
3. Generate automation tests  

## Setup

1. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Open http://127.0.0.1:5000 in your browser.

## Stack

- Python + Flask
- HTML / CSS / JavaScript
